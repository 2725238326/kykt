本仓库用于记录课程项目在不同阶段的资料、代码、实验结果与汇报材料。

当前阶段的核心工作围绕多视图三维重建展开，基于 `MVSNet` 方法完成了：

## 当前阶段重点内容

本阶段以 `MVSNet` 为基线方法，主要推进了以下工作：

1. 阅读论文《MVSNet: Depth Inference for Unstructured Multi-view Stereo》，梳理多视图深度推理与融合思路。
2. 获取并整理 `MVSNet_pytorch` 代码，明确 `train.py` 和 `eval.py` 为主要入口。
3. 在服务器上配置运行环境，准备 DTU 训练集与测试集路径。
4. 修复旧版代码在当前 PyTorch 环境下的兼容问题，包括投影、重采样、loss 接口与单卡训练流程。
5. 完成单卡训练、快速实验、推理与点云融合，生成 DTU 测试集点云结果。
6. 下载结果并整理为后续汇报、分析和继续优化提供基础。
