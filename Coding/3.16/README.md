# MVSNet 阶段性项目说明

## 1. 项目背景

本阶段工作以 ECCV 2018 论文 **MVSNet: Depth Inference for Unstructured Multi-view Stereo** 为出发点，结合其 PyTorch 复现仓库 `MVSNet_pytorch`，完成多视图立体重建流程的训练、推理、融合与结果整理。

当前阶段的目标不是一次性完成完整论文复现，而是先把以下链路打通：

- 论文阅读与核心思想整理
- 服务器环境搭建与代码兼容性修复
- DTU 数据集训练与测试流程跑通
- 深度图预测、置信度图生成与点云融合
- 形成可展示的阶段性结果与后续优化方向

## 3. 本阶段已完成内容

### 3.1 代码与环境

已完成以下基础工作：

- 确定基线方法为 MVSNet
- 整理并阅读论文核心思路
- 在服务器上完成运行环境准备
- 将训练数据与测试数据上传至服务器
- 打通从训练到推理再到融合的全流程

### 3.2 代码兼容性与工程修复

为了让旧版仓库能够在当前服务器环境中运行，本阶段对代码做了适配与修复，主要包括：

- 去除脚本中写死的 GPU 设定
- 修复新版本 PyTorch 下的投影/重采样兼容问题
- 修复旧式 loss 写法带来的 warning
- 将训练流程改为单卡稳定运行
- 为训练加入进度条显示
- 为赶时间的快速实验关闭每轮完整 test
- 新增快速训练列表 `train_fast16.txt`

### 3.3 训练与推理结果

本阶段已完成一版快速实验：

- 训练方式：单卡训练
- 训练策略：使用训练子集 `fast16`
- 训练目的：优先获得可运行结果，而不是追求最终 fully converged baseline
- 输出结果：
  - checkpoint
  - 深度图 `depth_est`
  - 置信度图 `confidence`
  - 融合点云 `.ply`

当前已经生成 22 个测试 scan 的点云结果，说明训练、推理、融合三条链路均已成功跑通。
