\begin{abstract}
近两年的三维重建研究中，DUSt3R 及其后继工作推动了一类新的 3R（feed-forward 3D reconstruction）范式：模型不再把稀疏匹配、相机估计、三角化和多视角融合完全拆成传统几何流水线，而是从图像对、多图集合或视频序列中直接预测点图、深度、相机、轨迹、置信度等几何中间量。该路线并未取消传统几何问题，反而把尺度、全局一致性、动态干扰、长序列漂移和输出可视化等问题重新组织到神经表示与测试时机制之中。本文围绕 DUSt3R、MASt3R、Fast3R、VGGT、CUT3R、Spann3R、MonST3R、Test3R、Splatt3R 等代表性工作，梳理点图表示、匹配增强、多视角规模化、状态与记忆、动态场景、测试时验证和 Gaussian 输出等分支。本文避免以单一模型为中心，也不将代码可运行或 demo 展示等同于质量领先；涉及性能、工程成熟度和应用可行性的判断均按论文、官方仓库或本地复现记录区分证据层级。综述最后讨论 3R 模型走向实际系统时仍需面对的质量评估、先验冲突、许可证和失败样本记录问题。
\end{abstract}

\noindent\textbf{关键词：} 3R；前馈式三维重建；DUSt3R；点图；视觉几何；动态场景；长序列重建；3D Gaussian Splatting

\section{引言}

传统三维重建通常以显式几何流程为中心：先进行局部特征提取和匹配，再估计相机位姿、三角化稀疏点，随后通过多视角立体、深度融合或 bundle adjustment 得到更完整的场景表示。这一流程的优势在于物理含义清楚、失败点相对可定位；限制则在于它对纹理、视角重叠、相机初始化和全局优化质量高度敏感，在互联网图片、移动端视频和动态场景中往往需要大量工程补丁。

DUSt3R 将这一问题重新组织为稠密 pointmap 预测：给定图像输入，模型直接输出每个像素对应的三维点及置信度，再通过对齐或下游过程派生相机、深度、点云和匹配信息\citep{dust3r}。这种表示并没有使尺度和一致性问题消失，但它把许多传统中间步骤压缩为可学习的视觉几何预测，从而形成了 MASt3R、Fast3R、VGGT、CUT3R、MonST3R 等一系列后续分支\citep{mast3r,fast3r,vggt,cut3r,monst3r}。

本文所称 3R 主要指这一类以神经网络前馈预测几何中间量的重建方法，范围覆盖图像对、多视角集合、视频、动态场景、长序列以及可渲染输出。Depth Anything、DINOv2、CoTracker、SAM2 等模型在本文中被视为支撑先验或辅助模块，而不是 3R 主线模型\citep{depth_anything,depth_anything_v2,dinov2,cotracker,sam2}。3DGS 和 4DGS 则主要作为输出表示和可视化层来讨论\citep{gaussian_splatting_3d,gaussian_splatting_4d}。

本文的证据边界如下。论文题目、摘要和方法图可支撑“模型关注的问题”和“公开声称的机制”；官方仓库可支撑代码、权重和 demo 状态；本地流程跑通只说明接口和依赖可以执行，不说明几何质量领先；未逐项核对实验表和许可证的结论，一律不写成确定性排行。这个区分对于近期 3R 文献尤其重要，因为许多工作仍处在预印本、项目页或早期开源阶段。

\section{从传统几何流程到点图表示}

前馈式三维重建的核心变化不是“用网络替代几何”，而是改变几何量被预测和校正的顺序。传统 SfM/MVS 把匹配、位姿、三角化、稠密化和融合分为若干显式阶段；pointmap 路线则把每个像素的三维落点作为中间语言，使深度、对应关系、点云和局部相机关系可以在同一表示下讨论。

这种变化带来三个直接后果。第一，模型可以在弱化相机先验的条件下工作，适合无序图像、稀疏视角和未知内参的输入。第二，匹配不再只是二维 descriptor 检索，MASt3R 等工作将匹配和三维几何 grounding 绑定，使对应关系可以服务于后续 SfM 或全局对齐\citep{mast3r,mast3r_sfm}。第三，多视角和视频扩展需要新的状态管理机制，因为成对 pointmap 的简单拼接不能自动保证长序列的一致性。

因此，DUSt3R 之后的研究并不是沿一条单线演进，而是分化为若干互补方向：匹配增强、多视角规模化、统一视觉几何预测、动态场景、长序列记忆、测试时修正和可渲染输出。图 \ref{fig:lineage} 给出本文采用的综述性谱系。

\section{基础谱系：DUSt3R、MASt3R 与多视角统一模型}

\subsection{DUSt3R 与 MASt3R}

DUSt3R 的意义在于提出了适合后续扩展的几何中间语言。它将图像对映射到稠密三维点图，并用 confidence 反映预测可靠性；多视角输入可通过成对预测和全局对齐组织起来\citep{dust3r}。从综述角度看，DUSt3R 更像是一种接口转向，而不是完整解决方案。它降低了相机先验门槛，但长序列、动态物体、遮挡、尺度漂移和大规模多图效率仍需额外机制。

MASt3R 在此基础上强调 3D-grounded matching，将匹配从单纯二维特征对应推进到与三维几何一致性相关的描述和检索问题\citep{mast3r}。MASt3R-SfM 进一步把这种匹配能力接回无约束 SfM 流程，用于图像检索、匹配和全局重建\citep{mast3r_sfm}。这一路线说明传统几何并未被废弃，而是在 3R 表示提供更强先验后，以新的接口回到系统中。

\subsection{多视角规模化与统一视觉几何}

多视角扩展是 DUSt3R 类方法的第一个主要压力点。若仍以图像对为基本单位，图像数量增加后会产生大量成对组合和对齐开销。Fast3R 以 many-view one-forward-pass 为目标，直接面向上千图像级别的前馈重建问题\citep{fast3r}。MV-DUSt3R+ 则沿 sparse-view reconstruction 方向推进，通过多视角 decoder 和 cross-reference fusion 处理少量视角下的场景重建\citep{mvdust3rplus}。

VGGT 将 camera、depth、pointmap 和 tracks 放在统一视觉几何预测框架下，体现了 3R 从“点图重建模型”向“通用几何预测模型”的扩展\citep{vggt}。MapAnything 进一步强调 metric feed-forward reconstruction，并允许多种可选输入条件进入模型\citep{mapanything}。Pow3R 关注 camera 和 scene priors 对无约束重建的帮助\citep{pow3r}。这些工作共同说明，多视角 3R 的关键不只是输入更多图片，而是如何处理相机、深度、轨迹、尺度和先验之间的约束关系。

\section{视频、动态场景与 4D 重建}

静态场景假设是许多三维重建流程的隐含前提。视频输入中一旦出现移动物体、非刚体运动或相机快速运动，单一静态点图会把时间变化错误吸收到几何结构中。Align3R 从动态视频的单目深度对齐入手，说明 Depth Anything 等深度先验可以为跨帧一致性提供有用约束，但单帧深度本身并不等价于完整多视角重建\citep{align3r,depth_anything_v2}。

MonST3R 直接面向运动存在时的几何估计，通常被视为 DUSt3R 之后动态场景分支的重要代表\citep{monst3r}。POMATO 将 pointmap matching 与 temporal motion 结合，D\textsuperscript{2}USt3R 将动态场景扩展到 4D pointmap 表示\citep{pomato,d2ust3r}。Easi3R 的位置应更克制地理解：它关注从 DUSt3R 中无训练地估计和分离运动，并不是重新训练一个动态三维 foundation model\citep{easi3r}。RayMap3R 则从 inference-time RayMap 和动态图像分支入手，尝试利用静态场景偏置来识别和抑制动态干扰\citep{raymap3r}。

\section{长序列重建中的状态、记忆与缓存}

长序列输入暴露了 3R 模型的第二个核心矛盾：模型需要在有限计算预算内记住足够多的几何上下文，同时避免错误状态被长期传播。CUT3R 以 persistent state 将连续 3D perception 组织为带状态的模型\citep{cut3r}；Spann3R 引入 spatial memory，用于更全局的 pointmap reconstruction\citep{spann3r}。这两类方法经常被同时称为“记忆增强”，但机制并不相同：前者更接近压缩状态递推，后者强调空间记忆对重建的支持。

Point3R 将 explicit spatial pointer memory 用于 streaming dense reconstruction\citep{point3r}。STream3R 和 LongStream 代表 causal/autoregressive 路线，强调顺序输入下的持续推理和 cache refresh\citep{stream3r,longstream}。LONG3R、LoGeR 和 Mem3R 则分别从长序列 gating/pruning、local-global hybrid memory 以及 tracking/mapping 解耦的混合记忆角度组织上下文\citep{long3r,loger,mem3r}。OVGGT、PAS3R、FILT3R 等近期工作进一步把固定预算 cache、pose-adaptive update 和 latent-state filtering 纳入讨论\citep{ovggt,pas3r,filt3r}。

\section{测试时验证、修正与先验输入}

3R 模型的输出通常包含 pointmap、depth、camera、tracks、confidence 等多个几何量。它们之间天然存在一致性关系，因此测试时验证不应只看渲染是否“好看”，还应检查跨视角、跨时间和跨输出的几何冲突。Test3R 利用测试时几何一致性学习来修正重建，适合讨论 triplet consistency 和 prompt tuning 的作用\citep{test3r}。TTT3R 将三维重建组织为 test-time training 问题，关注推理阶段状态更新\citep{ttt3r}。两者都属于测试时机制，但前者更偏一致性信号和提示调节，后者更偏状态/参数更新。

G-CUT3R 和 Pow3R 等工作说明 camera、depth、scene priors 可以显著改变 3R 的问题设置\citep{gcut3r,pow3r}。Depth Pro、Metric3D v2 提供 metric depth 或 surface normal 线索，DINOv2/DINOv3 提供视觉特征先验，CoTracker、SpatialTracker 和 SAM2 可用于跟踪或分割辅助\citep{depth_pro,metric3dv2,dinov2,dinov3,cotracker,spatialtracker,sam2}。这些先验不应被写成 3R 模型本身；更合适的表述是：它们为尺度、匹配、动态区域和失败检测提供外部约束，同时也可能引入先验冲突。

\section{从几何预测到可查看输出}

实际应用通常不直接消费模型内部的 pointmap。系统需要把几何预测转化为可查看、可比较、可归档的结果，例如深度图、点云、mesh、相机轨迹、置信度热力图、Gaussian 表示或失败样本报告。3D Gaussian Splatting 的价值在于实时可渲染表示\citep{gaussian_splatting_3d}；4DGS 和 4D-Rotor Gaussian Splatting 则面向动态场景的时变渲染\citep{gaussian_splatting_4d,rotor_4dgs}。它们是输出层和资产层的关键背景，但不是 pose-free 3R 的全部问题。

Splatt3R、InstantSplat 和 NoPoSplat 将前馈几何估计与 Gaussian 输出连接起来，分别面向 uncalibrated image pairs、sparse-view Gaussian Splatting 和 sparse unposed images\citep{splatt3r,instantsplat,noposplat}。这一路线对于 demo 和可视化尤其重要，但综述中需要保持两点谨慎：第一，Gaussian 渲染质量不等于底层几何完全正确；第二，代码、权重、许可证和显存依赖会直接影响应用可行性，不能只凭项目页效果图判断。

\section{讨论：近期 3R 文献的主要矛盾}

第一，模型统一性和输入条件之间存在张力。VGGT、MapAnything 等统一模型试图一次性输出多种几何量，但不同输入条件下的可靠性并不相同。综述写作中应把“模型支持某输入”与“该输入下质量可靠”分开。

第二，动态建模和长序列记忆相互关联但不能混同。动态方法处理的是物体或场景随时间变化的问题；长序列方法处理的是历史上下文如何保存、更新和遗忘的问题。一个模型可以支持视频输入，但不一定具有长期记忆；也可以有流式状态，但不一定能正确分离动态物体。

第三，测试时更新提高了适配能力，也带来额外成本和失败模式。Test3R、TTT3R、G-CUT3R 等工作说明推理阶段仍然可以利用一致性、状态更新和外部先验修正结果，但这些机制需要显式记录计算开销、收敛条件和先验冲突。对于应用系统而言，最危险的不是模型失败本身，而是失败没有被记录、置信度没有被解释，或质量结论脱离证据来源。

第四，Gaussian 输出提高了可视化吸引力，却容易掩盖几何问题。Splatt3R、InstantSplat 和 NoPoSplat 使无位姿或稀疏视角输入更容易转为可查看资产，但真实应用仍需回到重投影误差、跨视角一致性、视角外表现和许可证约束等指标。

\section{结论}

DUSt3R 之后的 3R 研究已经从单一的点图预测扩展为一组围绕视觉几何中间量的模型谱系：MASt3R 强化匹配，Fast3R 和 VGGT 推进多视角与统一几何预测，CUT3R、Spann3R 及后续方法处理长序列状态与记忆，MonST3R、Easi3R、RayMap3R 等工作关注动态场景，Test3R 与 TTT3R 把测试时一致性和更新机制引入重建过程，Splatt3R、InstantSplat、NoPoSplat 则把结果推向可渲染表示。

这些方向共同说明，近期 3R 的关键并不是简单追求“端到端”或“一个模型解决全部问题”，而是如何在不同输入情形下组织点图、相机、深度、轨迹、状态、先验和输出表示。未来综述和系统实现应继续区分论文机制、公开代码、本地可运行和应用质量四类证据，并把失败样本、质量检查和许可证记录纳入常规流程。只有这样，3R 模型才能从研究 demo 稳定地进入可复现、可比较、可交付的三维重建系统。
